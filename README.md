⚡ PokeApp React
Aplicación web interactiva desarrollada en React que consume la PokéAPI para visualizar información de Pokémon. El proyecto tiene como objetivo demostrar los fundamentos de desarrollo frontend, integrando el consumo de servicios REST, manejo de estados asíncronos y transiciones visuales.

🛠 Stack Tecnológico
Framework: React

Consumo de datos: PokéAPI (vía Fetch API)

Gestión de estado: React Hooks (useState, useEffect)

Estilos: CSS puro con animaciones y transiciones personalizadas

🚀 Cómo ejecutar el proyecto
Para clonar y poner en marcha la aplicación en tu máquina local:

Clonar el repositorio:

Bash
git clone https://github.com/EL4toCAARMINE/pokeApp.git
Acceder a la carpeta:

Bash
cd pokeApp
Instalar dependencias:

Bash
npm install
Lanzar la aplicación:

Bash
npm run dev
