# ⚡ PokeApp React

Aplicación web interactiva desarrollada en React que consume la **PokéAPI** para visualizar información de Pokémon. El proyecto tiene como objetivo demostrar los fundamentos de desarrollo frontend, integrando el consumo de servicios REST, manejo de estados asíncronos y transiciones visuales.

## 🛠 Stack Tecnológico

* **Framework:** React
* **Consumo de datos:** PokéAPI (vía Fetch API)
* **Gestión de estado:** React Hooks (`useState`, `useEffect`)
* **Estilos:** CSS puro con animaciones y transiciones personalizadas

## 🚀 Cómo ejecutar el proyecto

Para clonar y poner en marcha la aplicación en tu máquina local, sigue estos pasos desde tu terminal:

**1. Clonar el repositorio:**
```bash
git clone [https://github.com/EL4toCAARMINE/pokeApp.git](https://github.com/EL4toCAARMINE/pokeApp.git)
```

**2. Acceder a la carpeta:**
```bash
cd pokeApp
```

**3. Instalar dependencias:**
```bash
npm install
```

**4. Lanzar la aplicación:**
```bash
npm run dev
```

**5. Ver en el navegador:**
Abre tu navegador web y visita la dirección local que te indique la terminal (por defecto en Vite es la siguiente):
```text
http://localhost:5173
```

> *Nota: Asegúrate de tener instalado [Node.js](https://nodejs.org/) en tu sistema.*
